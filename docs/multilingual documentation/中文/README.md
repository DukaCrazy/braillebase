📘 BrailleBase — 内部架构概览（EN）
BrailleBase 由一组按编号划分的功能模块组成，每个模块负责内部逻辑的特定部分。
这种模块化结构提升了代码的可读性、可维护性、可扩展性，并便于多语言文档的组织。
以下是各模块的官方说明。

🧩 0001 — Registry 模块
负责管理字符及其对应的点字映射的内部注册表。
主要函数
- append_braille_letter
注册字母及其点字列表；若字母已存在，则覆盖原有映射。
- get_brailles_with_letter
返回已注册字母对应的点字列表。
- has_letter
检查某字母是否已注册。
- remove_letter
从内部注册表中移除字母。
模块职责
该模块相当于类的内部数据库。
所有翻译操作都必须经过此注册表。

🔤 0002 — Translate 模块
负责将文本转换为点字，再转换为数值索引。
主要函数
- translate_text_to_braille
将每个字符转换为一个或多个点字单元。
包含数字预处理（⠼）。
- translate_text_to_index
将点字符号列表转换为索引列表（0–63）。
模块职责
这是整个库的核心翻译引擎。
所有文本在导出或进一步处理前都会经过此模块。

🔁 0003 — Mapping 模块
提供以下直接映射：
- 点字 → 索引
- 点字符号列表 → 索引列表
主要函数
- get_braille_to_index
返回点字符号在 Unicode 点字区间（U+2800–U+283F）中的索引。
- get_braille_list_to_index_list
将整个点字符号列表转换为索引列表。
模块职责
这是整个库的数学核心。
所有数值转换均在此模块中完成。

📚 0004 — Tables 模块
包含内部使用的固定参考表。
主要函数
- braille_list
返回全部 64 个 Unicode 点字符号。
- get_binary_list
返回 64 组 6 位二进制数组（点字的二进制表示）。
- get_binary_string_list
返回 64 个 6 位二进制字符串。
模块职责
提供用于转换、验证和输出格式化的基础结构。

📤 0005 — Output 模块
负责格式化并导出处理后的数据。
主要函数
- output_all_json
以 JSON 格式导出文本、点字和索引。
模块职责
这是整个库的最终输出层。
所有从 BrailleBase 输出的数据都经过此模块。
