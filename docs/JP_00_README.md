📘 BrailleBase — 内部アーキテクチャ概要（JP）
BrailleBase は、内部ロジックを明確に分離するために、番号付きの機能グループで構成されています。
このモジュール構造により、可読性・保守性・拡張性・多言語ドキュメントの整合性が向上します。
以下は、各グループの公式説明です。

🧩 0001 — Registry group（レジストリグループ）
文字とその点字リストを管理する 内部レジストリ を扱います。
主な機能
- append_braille_letter
文字と対応する点字リストを登録します。既に存在する場合は上書きされます。
- get_brailles_with_letter
登録済みの文字に対応する点字リストを返します。
- has_letter
指定した文字が登録されているかを確認します。
- remove_letter
指定した文字を内部レジストリから削除します。
グループの役割
このグループはクラス内部の データベース として機能します。
翻訳処理は必ずこのレジストリを経由します。

🔤 0002 — Translate group（翻訳グループ）
テキストを 点字 に変換し、その後 インデックス（0〜63） に変換します。
主な機能
- translate_text_to_braille
各文字を 1 つ以上の点字セルに変換します。
数字の前処理（⠼）も含まれます。
- translate_text_to_index
点字リストをインデックスのリストに変換します。
グループの役割
このグループは 翻訳エンジンの中心 です。
すべてのテキストは、出力や後処理の前に必ずここを通ります。

🔁 0003 — Mapping group（マッピンググループ）
以下の変換を提供します：
- 点字 → インデックス
- 点字リスト → インデックスリスト
主な機能
- get_braille_to_index
Unicode 点字（U+2800〜U+283F）のインデックスを返します。
- get_braille_list_to_index_list
点字リスト全体をインデックスリストに変換します。
グループの役割
このグループはライブラリの 数値変換の中核 です。
数値化処理はすべてここで行われます。

📚 0004 — Tables group（テーブルグループ）
内部で使用する 固定テーブル を提供します。
主な機能
- braille_list
Unicode 点字 64 文字の完全リストを返します。
- get_binary_list
各点字を表す 6 ビット配列（64 個）を返します。
- get_binary_string_list
各点字を表す 6 ビットの文字列（64 個）を返します。
グループの役割
変換・検証・出力処理のための 基礎データ構造 を提供します。

📤 0005 — Output group（出力グループ）
処理済みデータの フォーマットとエクスポート を担当します。
主な機能
- output_all_json
テキスト・点字・インデックスを JSON 形式で出力します。
グループの役割
このグループはライブラリの 最終レイヤー です。
BrailleBase から外部へ出るデータはすべてここを通ります。
